Topologia de Nuvem & Monitoramento PaaS

Serviços gerenciados Microsoft Azure provisionados e telemetria ativa

PaaS Application

Azure App Service (Linux Web App)

Hospeda a aplicação Java 21 LTS com Spring Boot, balanceamento de carga nativo, certificados SSL gerenciados e suporte a escalabilidade horizontal.

  • Plano: B1 / F1 Service Plan
  • Deploy Automatizado: Azure CLI (az webapp deploy)
  • Protocolo: HTTPS TLS 1.3
PaaS Database

Azure SQL Database (SQL Server)

Banco relacional PaaS nativo com replicação e backups automáticos, protegido por Firewall de Rede e autenticação segura.

  • SGBD: Microsoft SQL Server v16+
  • Modelo Relacional: tb_dimdim_categoria (1) ➔ tb_dimdim_transacao (N)
  • Segurança: Variáveis criptografadas no App Settings
APM & Observability

Azure Application Insights

Monitoramento contínuo de latência, contagem de requisições HTTP, dependências JDBC no Azure SQL, Live Metrics e rastreamento de falhas.

  • Instrumentação: Java 3.x In-Process Agent
  • Métricas: Tempo de resposta de queries SQL e chamadas REST
  • Workspace: Azure Log Analytics integrado
